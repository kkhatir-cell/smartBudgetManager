Smart Budget Manager

Project Description

Smart Budget Manager is a simple application designed to help users manage their personal finances and control their expenses.

Main Features

- Track daily expenses.
- Manage monthly budgets.
- Categorize expenses.
- Monitor income and spending.
- Calculate the remaining budget.

Project Objectives

- Improve personal financial management.
- Help users control their spending.
- Encourage better saving habits.

Technologies Used

- Java
- Object-Oriented Programming
